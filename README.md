# 谁是卧底助手 开发文档（下一版本规划）

**目标版本**：v1.1.0  
**最后更新**：2026-03-05  
**状态**：规划中（用于指导下一阶段开发）

---

## 1. v1.1 版本目标

本版本核心目标是把“词库能力”从“内置静态筛选”升级为“可管理内容系统”，并增加对局信息公开策略配置。

### 1.1 功能目标（本次）
1. **取消词类分类选择**（不再按 category 进行开局筛选）。
2. **提供多个默认词库供用户选择**（如：经典、进阶、搞笑等）。
3. **新增词库编辑能力**：支持用户对词库执行编辑、启用/停用、导入、导出。
4. **新增出局身份显示选项**：可配置“出局后显示身份 / 不显示身份”。

### 1.2 不在本次范围
- 联机对战、账号系统、云端同步。
- 复杂权限系统（仅保留本地导入导出）。
- 多人协作编辑词库。

## 2. 与 v1.0 的关键变化

| 模块 | v1.0 现状 | v1.1 规划 |
|------|-----------|-----------|
| 开局筛选 | 分类 + 难度筛选 | 改为“词库选择”优先，不再展示分类筛选 |
| 词库来源 | 主要依赖 assets 静态文件 | 默认词库 + 用户词库并存 |
| 词库维护 | 开发者修改 JSON | 用户可在应用内编辑/启用/导入/导出 |
| 投票后信息 | 当前按既有逻辑展示 | 新增开关：出局后是否显示身份 |

## 3. 需求细化

### 3.1 设置页改造（Setup）

#### 保留
- 玩家数、卧底数设置。
- 开始游戏主流程。

#### 变更
- 移除“启用分类提示”和分类筛选入口。
- 改为“词库选择”组件：
  - 默认词库列表（单选）；
  - 可显示词条数量、是否启用；
  - 可进入词库管理页。

#### 新增
- 选项：`出局后显示身份`（布尔开关）。

### 3.2 词库管理页（新增）

建议入口：设置页 AppBar 或词库卡片中的“管理词库”。

功能点：
- 查看词库列表（默认词库 + 用户词库）。
- 词库启用/停用。
- 新建词库。
- 编辑词库（名称、词条增删改）。
- 导入词库（JSON 文件）。
- 导出词库（JSON 文件）。

### 3.3 投票页与结算页改造

- 新增配置字段：`revealRoleOnElimination`。
- 当玩家出局时：
  - 若开启：显示其身份（平民/卧底）。
  - 若关闭：仅标记出局，不显示身份。
- 结算页仍展示全量结果（建议保持）。

## 4. 数据与存储规划

### 4.1 词库模型建议

建议新增 `WordBank` 领域模型：
- `id`（唯一标识）
- `name`（词库名）
- `sourceType`（default / user）
- `enabled`（是否启用）
- `entries`（词条集合，每项含 civilian / undercover / difficulty）
- `updatedAt`

### 4.2 存储策略建议

- **默认词库**：继续放在 `assets`（只读）。
- **用户词库**：存放在应用本地可写目录（JSON）。
- **设置项**：保存用户偏好（选中词库、出局是否显示身份）。

> 建议引入本地持久化（如 SharedPreferences + 本地文件），避免每次启动丢失用户设置。

### 5.1 服务层
- `WordPoolService`：从“按 category 合并”调整为“按 selectedWordBankIds 装载”。

  - 读取/保存用户词库

### 5.2 页面层
- `SetupScreen`：
  - 移除分类逻辑状态；
  - 增加词库选择状态；
  - 增加 `revealRoleOnElimination` 配置。
- 新增 `WordBankManageScreen`（建议名）：管理词库。

### 5.3 对局模型
- 对局配置增加字段：
  - `selectedWordBankIds`
  - `revealRoleOnElimination`

## 9. 风险与注意事项

- **兼容风险**：旧版分类数据迁移后可能失效，需要给出降级策略。
- **数据质量风险**：导入 JSON 结构不合法，需要完整报错提示。
- **体验风险**：词库管理入口过深会降低可发现性，建议设置页直达。
