@startuml
start
:接收玩家数 N, 卧底数 U;
:校验: U < N?;
if (校验通过?) then (是)
  :从词库中随机选取一组词对;
  :获得平民词 Wc, 卧底词 Wu;
  :创建 N 个玩家对象;
  :随机生成 U 个不重复的索引作为卧底;
  :遍历所有玩家;
  if (当前索引在卧底集合中?) then (是)
    :设置玩家角色=卧底, 词汇=Wu;
  else (否)
    :设置玩家角色=平民, 词汇=Wc;
  endif
  :打乱玩家顺序(可选);
  :初始化游戏状态;
  :进入游戏主持页;
else (否)
  :显示错误提示;
  :返回设置页;
endif
stop
@enduml
