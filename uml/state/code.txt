@startuml
state "设置页" as Setup
state "游戏主持页" as Host
state "投票页" as Vote
state "结果弹窗" as Result

[*] --> Setup : 打开App

Setup --> Host : 开始游戏(玩家数,卧底数)
Host --> Host : 下一玩家\n(切换当前显示)
Host --> Vote : 点击投票(可选)
Vote --> Host : 确认淘汰\n(若游戏未结束)
Host --> Result : 游戏结束\n(胜负已分)
Result --> Setup : 再玩一局
@enduml
